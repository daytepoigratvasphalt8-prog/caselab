# CaseLab

Симулятор открытия кейсов CS2 на виртуальные деньги: 48 кастомных кейсов, батлы с ботами и друзьями онлайн, апгрейд, контракты.

- Деньги виртуальные, реальных платежей и вывода предметов нет.
- Цены скинов: steamdb.com и csdb.gg на 27.10.2026, пересчёт по курсу ЦБ 80,49 ₽ за $1.
- Картинки скинов: Valve / CS2 (из проекта Nereziel/cs2-WeaponPaints), данные о скинах: ByMykel/CSGO-API.
- Онлайн-батлы идут через публичные MQTT-брокеры (EMQX, HiveMQ, Mosquitto) по WebSocket: своего сервера не нужно, подключение сразу к нескольким, чтобы работало даже если один недоступен.
- Прогресс хранится в браузере (localStorage).

Сайт — один файл `index.html`. Чтобы опубликовать: Settings → Pages → Deploy from a branch → `main` / root.
